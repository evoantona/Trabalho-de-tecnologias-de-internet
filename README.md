# Projeto Página Web Multitemática

## Descrição
Aplicação web que demonstra o uso de AJAX, WebSocket, Node.js e Bootstrap, com três páginas interativas:
- index.html: Formulário de contato com AJAX.
- chat.html: Chat em tempo real com WebSocket.
- stock.html: Atualizações de estoque em tempo real com WebSocket.
